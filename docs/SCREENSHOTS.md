# Sinu Stuudiumi ekraanipiltide võtteplaan

Staatus: logo on lisatud; ekraanipildid on veel loomata

Ekraanipiltidel ei tohi olla päris õpilase nime, hindeid, puudumisi, sõnumeid, tunniplaani, klassi liikmeid, sisselogimisandmeid, brauseriprofiili ega muud privaatset infot. Eelista kohalikku sanitaarset demonstratsioonivaadet päris konto hilisemale hägustamisele.

## Vajalikud arvutipildid

### 1. Põhikuva

- Mõõt: 1280 × 800 pikslit.
- Sisu: sanitaarne TORG Stuudiumi töölauavaade Graphite Minti kujundusega.
- Olek: külgmenüü ja põhisisu nähtavad, ükski menüü ei kata sisu.
- Kasutus: README põhikuva ja Chrome Web Store'i esimene ekraanipilt.

### 2. Kujunduse valimine

- Mõõt: 1280 × 800 pikslit.
- Sisu: Sinu Stuudiumi seadete leht koos kujunduste valikuga.
- Olek: täiendus sisse lülitatud, valitud kaart selgelt nähtav.
- Kasutus: README ja Chrome Web Store'i teine ekraanipilt.

### 3. Praktiline täiustus

- Mõõt: 1280 × 800 pikslit.
- Sisu: sanitaarne Stuudiumi vaade, mille menüüs on nähtav „Teema seaded”.
- Olek: menüü avatuna, kuid ilma kasutajanimede või muude isikuandmeteta.
- Kasutus: Chrome Web Store'i valikuline kolmas ekraanipilt.

## Vajalikud telefonipildid

### 4. Androidi põhikuva

- Mõõt: telefoni algne portree-ekraanipilt ilma vähendamise või sõnumiriba teadeteta.
- Sisu: sanitaarne õpilase töölauavaade Graphite Minti kujundusega.
- Olek: leht täielikult laetud; allatõmbega värskendamise indikaator ei ole nähtav.
- Kasutus: README Androidi eelvaade.

### 5. Androidi seaded

- Mõõt: sama telefoni algne portree-ekraanipilt.
- Sisu: Sinu Stuudiumi kujunduse valimine Androidis.
- Olek: sama valitud kujundus nagu arvutipildil.
- Kasutus: README teine Androidi pilt.

### 6. Allatõmbega värskendamine

- Mõõt: sama telefoni algne portree-ekraanipilt.
- Sisu: sanitaarne Stuudiumi vaade Androidi loomuliku värskendusindikaatoriga.
- Kasutus: valikuline funktsioonipilt; ei ole põhilise pildikomplekti jaoks kohustuslik.

## Logo lähtevara

Lõplik hele, tume ja läbipaistva taustaga PNG-lähtevara asub kaustas `assets/brand/`. Platvormide ikoonid luuakse neist lähtevaradest; eraldi väikeseid faile ei ole vaja käsitsi valmistada.

## Poe eraldi graafika

- **Ikoon:** 16 × 16, 32 × 32, 48 × 48 ja 128 × 128 PNG.
- **Väike reklaampilt:** 440 × 280 PNG või JPEG.
- **Valikuline suur reklaampilt:** 1400 × 560 PNG või JPEG.

Reklaampiltidel kasuta Sinu Stuudiumi märki, nime, tunnuslauset, grafiiti ja mündirohelist. Ära kasuta ametlikku Stuudiumi või TORGi logo ilma loata.

## Enne pildistamist

1. Kasuta täpselt avaldamiseks mõeldud tootmis- või beetaversiooni.
2. Lülita välja kõik teised Sinu Stuudiumi laienduse eksemplarid.
3. Kontrolli, et pilt ei sisaldaks brauseri järjehoidjaid, kontopilti, e-posti aadressi ega süsteemiteavitusi.
4. Kontrolli pärast salvestamist pilti täissuuruses, mitte ainult pisipilti.
5. Säilita algsed võttefailid ainult siis, kui need ise ei sisalda tundlikku infot.
